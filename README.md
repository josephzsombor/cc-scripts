# TKG-CC-scripts
This repository is for scripts for common tasks on ComputeCanada clusters within The Kennepohl Group.

- Simple bash scripts for SLURM tasks such as job submission and file management are under /bin. This is ~/bin on the cluster
- Bash scripts for data processing currently go in /. These scripts get copied into ~/projects/job subirectories on the cluster
- This branch was created for 12-03-2025 Kennepohl Group meeting
